AI ENGINEERING CURRICULUM

개념에서 운영 가능한 AI 서비스까지

아래 4개 모듈은 커리큘럼 초안입니다. 학습자 수준과 모델·플랫폼 변화에 맞춰 구성과 기간을 조정합니다.

MODULE 01 · FOUNDATION

AI 애플리케이션 기초

Python과 API 기반으로 모델의 입력과 출력, 제한사항, 비용 구조를 이해합니다.

  • Python 환경·HTTP·JSON
  • 모델 API와 구조화된 출력
  • 프롬프트 설계·컨텍스트 관리
MODULE 02 · BUILD

검색 증강·에이전트 개발

외부 문서와 도구를 연결해 실용적인 AI 기능을 만듭니다.

  • 임베딩·검색·RAG 설계
  • 툴 호출과 실행 흐름 제어
  • 데이터 파이프라인·캐싱
MODULE 03 · EVALUATE

품질 평가와 신뢰성

실험과 테스트로 AI 시스템의 성능을 측정하고 개선합니다.

  • 평가 데이터셋·정량 지표
  • 환각·실패 모드 분석
  • 지연시간·토큰 비용 최적화
MODULE 04 · OPERATE

배포·운영·보안

사용자-facing 서비스를 안전하고 관찰 가능한 형태로 운영합니다.

  • 서버·인증·로그·모니터링
  • 프롬프트 인젝션·권한 분리
  • 버전 관리·운영 실험·회귀 테스트

확인 사항

정식 교재나 수업을 지금 구매할 수 있나요?

아닙니다. 교육과정 기획 단계로 판매·선결제는 운영하지 않습니다. 향후 판매 여부·가격·구성은 별도로 공개합니다.

AI Engineering이라는 기존 출판물과 관련이 있나요?

이 페이지는 AI 엔지니어링 기술 분야를 주제로 하는 STARGATE EDU 독립 교육 트랙 기획안이며, 동일하거나 유사한 제목의 기존 도서 출판사·저자와 제휴하거나 승인받은 프로그램이 아닙니다.

알고리즘 교재와 어떤 관계인가요?

4년 완성 알고리즘이 문제 해결과 자료구조·복잡도에 집중한다면, AI Engineering 트랙은 이론을 활용해 실제 AI 애플리케이션을 구축하고 평가·운영하는 흐름에 집중합니다.
